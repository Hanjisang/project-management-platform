# SOP 与实施计划

SOP 模板包含版本、阶段、任务和检查项。版本只允许在 DRAFT 状态编辑；发布后内容不可变。发布前系统校验层级、工期和必需交付物，并依据工期自动归一化权重到 100%。

项目选择已发布版本后生成独立 ProjectPlan 快照。实际负责人、日期、完成状态、进度和项目交付文档只存在于快照/项目侧，不反向污染模板。

升级流程：选择新版本 → 通过稳定键计算 ADD/UPDATE/REMOVE 差异和 diffHash → 用户审阅 → 服务端重算防止过期预览 → 事务同步模板字段并保留执行数据。已产生业务数据的节点不会被破坏性删除。

计划进度由检查项和任务进度向阶段、计划和项目逐级重算。项目结项会检查必需计划任务、普通任务、高风险问题和必需交付物。

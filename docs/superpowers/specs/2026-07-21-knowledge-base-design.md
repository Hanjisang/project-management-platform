# 数据中心知识库设计

## 目标

在数据中心新增可实际使用的知识库，统一承载标准知识与项目沉淀。知识条目支持在线正文、附件、分类、标签、检索、审核和发布。

## 信息架构

- 标准知识：实施经验、常见问题、操作手册、接口规范、产品资料、培训资料、项目案例。
- 项目沉淀：由已审核通过的项目交付文档，经项目负责人手动“一键沉淀”生成。
- 分类：固定一级分类，可维护二级分类。
- 状态：草稿、待审核、已发布、已驳回、已归档。

## 页面

### 数据中心入口

新增知识库卡片，展示已发布知识数、待审核数，并进入知识库主页。

### 知识库主页

- 顶部概览：知识总数、已发布、待审核、项目沉淀。
- 检索：关键词、一级分类、来源、状态。
- 列表：标题、摘要、分类、标签、来源、作者、更新时间、状态、操作。
- 操作：查看、新建、编辑、删除、提交审核、审核发布。

### 知识详情与编辑

- 详情展示标题、摘要、正文、分类、标签、来源项目、附件、发布信息。
- 编辑包含标题、摘要、正文、一级分类、二级分类、标签、附件和发布方式。

### 项目文档沉淀

仅已通过或已确认的项目文档显示“一键沉淀”。操作时填写标题、摘要、分类、标签，系统保留项目、任务、输出物和原文档关联。

## 数据模型

- `knowledge_articles`：标题、摘要、正文、分类、标签、来源、来源项目、来源文档、作者、状态、审核信息和时间。
- `knowledge_attachments`：知识条目、文件名、对象键、类型、大小和时间。
- `knowledge_categories`：父级、名称、排序和状态。

## 权限

- `knowledge.view`
- `knowledge.create`
- `knowledge.edit`
- `knowledge.review`
- `knowledge.delete`

普通用户可创建草稿并提交审核；系统管理员可直接发布和审核。

## 接口

- `GET/POST /api/knowledge`
- `GET/PUT/DELETE /api/knowledge/:id`
- `POST /api/knowledge/:id/submit`
- `POST /api/knowledge/:id/review`
- `GET /api/knowledge/:id/attachments/:attachmentId/download`
- `POST /api/projects/:projectId/documents/:documentId/deposit`

## 验收标准

- 数据中心可进入知识库。
- 搜索和筛选即时生效。
- 知识条目支持完整增删查改。
- 审核状态流转正确。
- 已审核项目文档可一键沉淀且保留来源。
- 权限能控制菜单和操作。
- 桌面端界面与现有项目风格一致。

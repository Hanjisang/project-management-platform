# 全量 UI 与功能验收设计

## 目标

对实施项目管理平台进行一次上线级全量验收，覆盖桌面端与 iPhone 14 Pro 尺寸移动端，清除冗余按钮和历史术语，修复不可达控件、布局溢出、触控尺寸不足及验收中发现的功能问题。

## 设计原则

- 不改变现有业务数据，不执行新增、删除、停用等破坏性验证。
- 用户权限模块只呈现“用户”和“角色”，权限分为菜单权限与操作权限。
- 无实际行为的入口直接移除，不保留占位按钮或假功能卡片。
- 同一类动作统一使用简短名称，例如“重置”，避免“重置筛选”等混用。
- 移动端不依赖横向滚动才能完成核心操作；表格在窄屏转为纵向卡片。
- 主要操作按钮在移动端保持至少 44px 的可触控高度。
- 保留全局返回能力与页面状态恢复，移除页面内重复返回按钮。

## 本轮重点

1. 修正用户与角色页面仍出现“组织部门”的旧文案和统计项。
2. 移除数据中心“导出记录”等无行为按钮及系统设置中的占位功能卡片。
3. 将用户、角色、知识库、禅道任务等宽表格改为移动端卡片布局。
4. 修复检查项筛选器、交付物关联按钮及 SOP 图标按钮在移动端不可达或过小的问题。
5. 为纯图标按钮补充明确的无障碍名称和操作提示。
6. 统一分析、重置等术语，清理重复与不相称表述。

## 验收标准

- 桌面端 1440×900 和移动端 393×852 下，核心页面无页面级横向溢出。
- 核心按钮均可见、可点击，移动端不需要横向拖动才能操作。
- 浏览器控制台无新增错误。
- 自动化回归测试全部通过。
- 线上容器健康，入口返回 HTTP 200。
